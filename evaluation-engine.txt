# OR

## Sparse mask evaluation
    * Start with all active positions
    * Evaluate each term
        * For each active position
            * if expression is false, add to survivor list
    * Compute complement of survivor list

        Equivalent to:

            OR(f1, f2, ..., fN) == ~AND(~f1, ~f2, ..., ~fN)

## Dense mask evaluation
    * Start with all false masks
    * Evaluate each term
        * result[i] = result[i] || <term>
